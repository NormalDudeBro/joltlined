Practice (answers below)

1. Trace a browser request to a remote server and explain what a router changes.

Transport and IP headers are carried inside a local-link frame. The router removes the incoming link framing, chooses a next hop by IP routing, and sends the packet in a new outgoing-link frame; link MAC delivery changes hop by hop.

2. Does a switch always mean it cannot route between subnets?

No. An ordinary Layer 2 switch forwards frames within its VLAN, but a Layer 3 switch can route between configured networks. The device label alone does not specify enabled functions.

Practice (answers below)

1. Calculate the network and ordinary LAN usable range for 192.0.2.70/26.

The block has 64 addresses and begins at .64. Mask is 255.255.255.192; ordinary LAN convention treats .64 as network and .127 as broadcast, leaving .65-.126. A /31 point-to-point link is a defined exception.

2. Why are Class A/B/C masks not used to determine a modern prefix?

CIDR uses an explicitly configured prefix length and classless allocation. Historical classes are useful as history, but the address's first octet does not determine its current subnet mask.
