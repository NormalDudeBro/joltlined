o From device to ISP
-> A network adapter connects a device to a wired or radio link.
-> A switch or access point joins devices to the local LAN.
-> A router joins IP networks and selects a route toward the ISP.
-> A modem adapts signaling for a provider medium such as coax.
-> An optical network terminal adapts a fiber access connection.
-> A gateway may combine modem, routing, switching and Wi-Fi.
-> The ISP aggregates access and routes to other networks.
-> Operators interconnect through peering or paid transit.
-> Available access media depend on the local provider.
o ISP chain and local limits
-> A home link does not directly cable to every Internet host.
-> Traffic crosses local gear, then provider networks.
-> Fiber, coax, DSL and cellular differ in signaling and reach.
-> The provider medium and plan constrain the access link rate.
-> A live physical link does not prove DNS or routing is working.
-> A reachable router does not prove remote service works.
-> Power or ISP faults can interrupt a correctly addressed LAN.
-> Speed tests include remote path and server limitations.
-> Check link, route, DNS and remote service separately.
-> One device may combine modem and router functions.

o IPv4 and IPv6 formats
-> IPv4 addresses are 32 bits, commonly shown as four octets.
-> Each dotted-decimal octet ranges from 0 through 255.
-> IPv6 addresses are 128 bits, written as hexadecimal groups.
-> IPv6 uses colons; :: can compress one run of zero groups.
-> IPv6 greatly expands available address space over IPv4.
-> IPv6 has a different header and uses Neighbor Discovery.
-> IPv4 commonly uses ARP on Ethernet links for local resolution.
-> Dual stack runs IPv4 and IPv6 together during transition.
-> IPv6 still needs suitable access policy and configuration.
o Subnet calculation example
-> For 192.0.2.70/26, six bits remain for host positions.
-> A /26 block has 64 total addresses.
-> The aligned block containing .70 starts at 192.0.2.64.
-> The dotted mask is 255.255.255.192.
-> Under ordinary LAN convention, .64 is the network address.
-> The corresponding broadcast address is 192.0.2.127.
-> Ordinary assignable range is 192.0.2.65 through .126.
-> State the address-use convention when describing host range.
-> A /32 denotes one IPv4 address route, not a LAN subnet.
-> A /31 is a point-to-point exception to ordinary host rules.
