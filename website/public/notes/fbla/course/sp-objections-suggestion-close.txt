o Overview
-> Listen and clarify
-> Respond and check
o Listen and clarify
-> An objection signals concern; it is information to understand.
-> Listen without interruption or a defensive rebuttal.
-> Acknowledge the concern without falsely agreeing.
-> Clarify: compared with which option, price, or scope?
-> Distinguish price, timing, fit, trust, or authority concern.
-> Ask whether another issue remains before responding.
-> Do not treat objection as consent to pressure.
-> Do not manufacture urgency or shame hesitation.
-> Restate concern briefly and invite correction.
o Respond and check
-> Answer the concern using verified offer facts.
-> Compare options on the same scope and time period.
-> For price, explain included scope and actual alternatives.
-> Offer a smaller option only if it truly exists and fits.
-> For timing, discuss feasible start dates or no purchase.
-> Admit unknowns; seek permission to verify and follow up.
-> Ask whether the answer addressed the concern.
-> If unresolved, summarize the gap and accept it.
-> A concession changes terms; disclose its real conditions.
-> Do not hide terms or make unsupported counterclaims.
o Overview
-> Suggest related value
-> Close as a clear choice
o Suggest related value
-> Suggestion selling offers an additional related item/service.
-> Offer only when it supports a confirmed customer need.
-> Example: training may help a team new to the workflow.
-> Explain distinct scope, price, and optional status.
-> Ask permission; accept refusal without changing core terms.
-> An add-on should strengthen use or outcome, not ticket size.
-> Do not bundle unrelated goods or obscure material conditions.
-> Check added cost against buyer's priorities and constraints.
-> More products are not automatically better fit.
o Close as a clear choice
-> A close requests a decision or concrete next action.
-> Confirm fit, terms, unresolved objections, and authority.
-> If ready, ask for the stated plan and quantity.
-> If not ready, agree on information or follow-up by consent.
-> Name owner, action, and date for a service next step.
-> Clear intent comes from buyer's stated choice, not guesswork.
-> Silence or hesitation is not consent to buy.
-> Accept no or delay without repeated pressure.
-> Record agreed scope and price before confirming commitment.
-> FBLA top close band reflects evident buyer intent.
